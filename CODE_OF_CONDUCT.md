# NetObserv Project Code of Conduct

The NetObserv project has adopted the [CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).
All community members, contributors, and participants in the NetObserv project are expected to abide by this Code of Conduct. This includes respectful treatment of everyone, regardless of their background or identity.
